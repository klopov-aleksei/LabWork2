# General System Description

This RPG combat system is designed as a modular C++ application allowing players to create and customize characters, engage in turn-based combat against AI-controlled enemies, and use a variety of skills, items, and equipment. The system focuses on:

- **Extensibility**: New character classes, skills, and items can be added with minimal changes.
- **Modularity**: Separation of concerns via clear component and class boundaries (e.g., CharacterCreation, CombatSystem, Inventory).
- **Reliability**: Comprehensive error handling and unit tests ensure stability.
- **Usability**: Text-based interface allowing interactive character creation and combat options.
